### TC-ARP-05. Видалення та очищення записів ARP-кешу (власний)

|                     |                                                     |
|---------------------|-----------------------------------------------------|
| **ID**              | TC-ARP-05                                           |
| **Назва**           | Видалення та очищення записів ARP-кешу (власний)    |
| **Пріоритет / тип** | Medium / функціональний                             |
| **Передумови**      | В ARP-кеші PC1 є динамічний запис для 192.168.10.2. |
| **Тестові дані**    | IP PC2 = 192.168.10.2                               |

| **№** | **Дія (крок)**                                                                | **Очікуваний результат**                                  |
|-------|-------------------------------------------------------------------------------|-----------------------------------------------------------|
| 1     | sudo arp -d 192.168.10.2, потім arp -a                                        | Запис видалено                                            |
| 2     | ping -c 1 192.168.10.2, потім ip neigh show                                   | Запис створено знову (REACHABLE)                          |
| 3     | sudo ip neigh del 192.168.10.2 dev veth-pc1, потім ip neigh show              | Запис видалено                                            |
| 4     | Створити запис ping-ом, виконати sudo ip neigh flush all, потім ip neigh show | Усі динамічні записи видалено                             |
| 5     | Додати статичний запис, виконати sudo ip neigh flush all, потім ip neigh show | Статичний (PERMANENT) запис НЕ видаляється командою flush |
| 6     | sudo arp -d 192.168.10.2, потім ip neigh show                                 | Статичний запис видалено                                  |

|                         |                                                                                                                                                                         |
|-------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Фактичний результат** | Усі кроки дали очікуваний результат. Підтверджено важливу особливість: ip neigh flush all не видаляє статичні записи, їх треба видаляти явно (arp -d або ip neigh del). |
